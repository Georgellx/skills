# Content development and hard gates

## Route selection

Use the route that best matches the material:

| Route | Best for | Typical progression |
| --- | --- | --- |
| Story | Emotion, relationship, memory, transformation | normal state -> trigger -> carryover -> interruption -> action -> resolving image |
| Teaching/example | Method, language learning, practical guidance | concrete problem -> failed/common response -> reason -> demonstration -> application -> takeaway |
| Visual metaphor | Abstract feeling with little factual narrative | object/state -> pressure -> distortion -> intervention -> changed state -> afterimage |

Do not force every source into an emotional story. Do not disguise a list as a story by adding a mascot beside each bullet.

## One-sentence test

Before writing scenes, complete this sentence:

```text
[Protagonist] encounters [specific event], responds by [visible action], and ends in [changed state or resolving image].
```

If the sentence contains only concepts such as healing, growth, sensitivity, confidence, or boundaries, make the event and action more concrete.

## Scorecard

Score each item 0, 1, or 2. Require at least 9/12 and no critical failure before image generation.

| Criterion | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Specificity | Abstract claim | Some context | Concrete incident, object, place, or behavior |
| Causality | Scenes are separate points | Loose connection | Each scene causes or reframes the next |
| Visibility | Mostly explanation | Mixed | Every scene has a drawable event |
| Progression | Same state throughout | One weak change | Clear state/information changes |
| Ending payoff | Slogan only | Partial closure | Final image resolves or echoes the opening |
| Subtitle quality | Labels/exposition | Understandable | Natural, concise, and complementary to image |

## Critical failures

Revise regardless of score if any is true:

- A personal experience is invented and presented as the user's true story.
- More than half the scenes are definitions, instructions, or slogans rather than visible events.
- The relationship or source of conflict is unclear.
- The same emotional beat repeats without escalation or change.
- Removing a middle scene changes nothing.
- The ending depends entirely on a motivational sentence.
- English is a literal translation that sounds unnatural when spoken.

## Subtitle rules

- Keep one Chinese thought per scene unless pacing requires a deliberate split.
- Use plain spoken Chinese rather than essay language.
- Adapt English for meaning, rhythm, and natural speech. Preserve names only when needed.
- Do not include titles, speaker labels, scene numbers, instructions, or markdown in SRT cue text.
- If narration will be recorded manually, treat initial scene durations as estimates. Update timing after real audio when necessary.
